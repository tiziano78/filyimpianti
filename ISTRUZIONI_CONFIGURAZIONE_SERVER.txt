3. MONITORAGGIO ERRORI (OPZIONALE MA CONSIGLIATO)
-----------------------------------------
Per monitorare gli errori dell'applicazione, è consigliato attivare Sentry:
1. Registrarsi su https://sentry.io
2. Creare un nuovo progetto Next.js
3. Copiare il DSN fornito
4. Sostituire "your_sentry_dsn" nel file .env.production con il DSN reale

4. LOGGING CENTRALIZZATO (OPZIONALE)
-----------------------------------------
Per un logging centralizzato, è possibile attivare Logtail:
1. Registrarsi su https://betterstack.com/logtail
2. Creare un nuovo source
3. Copiare il token fornito
4. Sostituire "your_logtail_token" nel file .env.production con il token reale
